# tools/ · 构建和测试脚本

所有脚本都按仓库根目录定位，不依赖 box 上的绝对路径。浏览器类脚本使用 `playwright-core` 和系统里的 Chrome（`/usr/bin/google-chrome`，带 `--no-sandbox`）。

```bash
npm --prefix tools ci                 # 安装依赖（只装 playwright-core，不下载浏览器）
python3 -m http.server 8765           # 在仓库根目录起服务；大多数脚本默认用 http://127.0.0.1:8765
PF_URL=http://127.0.0.1:8770 node tools/fps.js   # 换端口（多个 worktree 并行时）
```

| 脚本 | 用途 |
|---|---|
| `smoke.js` | **冒烟测试（CI 用）**。自己起服务，用 http 和 `file://` 加载，跑一天，转 4 个角度。出现报错或画面空白时返回非 0。 |
| `xhs-save-test.js` | 小红书小工具存档：1MB/10MB 配额、损坏主档回退 `:bak`、合成后期存档体积（不得改网页版行为）。 |
| `path-test.js` | **寻路单元测试（CI 用）**，不开浏览器：A* 绕过障碍、不允许斜切角落、到不了的目标退到最近可走格、泥土路偏好、房子/池塘/栅栏上的脚本路线绝不进入阻挡格、未解锁区域封住、扩建后的房子、棚子篱笆和海边码头可达性、路径缓存和全图 100 条路线的性能。 |
| `path-shots.js` | 画出绕过房子、池塘、栅栏的寻路路线（带调试叠层），写入 `/workspace/pf-shots/path_*.png`（可用 `PF_SHOTS` 改目录）。 |
| `save-test.js` | **存档和数值单元测试（CI 用）**，不开浏览器：迁移链、坏档回退、新版存档不覆盖、导出导入、节奏和离线结算规则、区域价格和地图布局、果树结果周期、砍树产出；v4.5 起还测动物照顾和产量、牧场的商店前置条件、v5→v6 迁移；v4.7 起测每种动物的「区域 + 棚子」前置、每个棚子各自的饲料槽、猪的松露周期、猫狗加成、v6→v8 迁移不丢动物和建筑；v5.0 起测砍树范围（家门口 / 已买区域、果树和边框森林不砍、只有林场再生）、掉落概率、房子和篱笆的木材价格、好感 / 搬来 / 孩子出生和成长、孩子能干的活、v8→v9 迁移；v5.4.0 起测 v9→v10 迁档会从渔获补图鉴，新字段合法。`fixtures/` 里每个存档版本至少留一个样例。 |
| `save-smoke.js [--write-fixture]` | **存档浏览器测试（CI 用）**：保存后刷新状态一致、每个样例存档能加载并跑一天、坏档用备份、离线收益、导出导入和重置、耕地不退化。`--write-fixture` 会生成 `fixtures/save-v<当前版本>-day4.json`（只在升存档版本时用）。还测商店：面板购买、升级刷新后保留、倍速按钮、旧存档升级、宽锄头 3×3、收获留种、草莓重复采摘。；v4.3 起还测区域购买、砍树和移植指令、果园摘果卖钱、平移和小地图；v4.5 起还测牧场一栏和「先买」提示、买齐动物后任务板喂食加水捡蛋挤奶、产品卖钱、挨饿掉心情、刷新后动物还在。 v4.7 起还测：家门口鸡舍不用区域就能买、四个棚子跟着区域解锁并被照顾、猫狗跟随 / 抚摸 / 送种子 / 刷新后还在、v6 牧场存档读进 v8 什么都不丢。v5.0 起测：家门口的树砍了不再长、树桩夜里挖走、木材不够买不了房子、送花加好感一天一次、阿禾搬来、一家四口同一张任务板不抢同一个目标、晚上都回家、刷新后家人和庄园还在。`PF_ONLY=正则` 只跑名字匹配的测试。 |
| `econ.js [天数=20] [seed]` | 用真实游戏无头跑 N 天，脚本玩家按固定顺序买商店物品，打印每天收入、每次购买的游戏日和真实分钟数、种子来源（拔草 / 收获 / 购买 / 卖出）。v4.3 起脚本玩家买了斧头和林场后每天标 2 棵树砍，树苗按固定位置移植，另外打印木材和水果收入、结果的果树数。v4.5 起还买动物；v4.7 的清单在买完布鞋后先盖鸡舍养鸡、中途买猫狗，猪圈 / 羊圈 / 牛棚各自紧跟在林场 / 果园坡 / 北牧场之后，共 15 只动物，另外打印动物数、产品收入、买干草花的钱和平均心情。v5.0 的清单在买大篮子后就买斧头，每天标最近的 3 棵能砍的树，房子三档和篱笆插在中间，另外打印仓库木材、累计砍下的木材、阿禾好感、家里人数，以及认识 / 搬来 / 孩子出生的日子和砍树掉落统计。粒子特效改用自己的随机数后，同一个 seed 每次跑出的结果完全一样。设计稿的收入数字来自这里。 |
| `wood-test.js` | **木材自动化单元测试（CI 用，v5.3.1）**，不开浏览器：每棵树的木材（8 份、斧头升级 +2/+4、伐木小屋在林场 +2）、砍一棵的时间、自动砍树的目标（下一样要木材的建筑，不超过仓库）、只砍林场的野树且总留 3 棵、伐木小屋用树苗补种后 3 晚长回来（没有小屋 5 晚）、离线木材不超过目标。 |
| `wood-sim.js <存档.json> [天数=20] [idle\|mark] [购买顺序]` | 从一个导出的存档无头接着玩 N 天，打印每天的木材、砍下的木材、林场里长好的树，以及庄园在第几天买到。`mark`：玩家每天早上把林场所有长好的树都标上（旧版本最多能做到的）；`idle`：玩家一棵也不标。购买顺序如 `axe,axe,lumber,house`。 |
| `wood-shots.js <存档.json>` | 从存档买下斧头升级和伐木小屋，跑到农夫自己去林场砍树，截图写入 `/workspace/pf-shots/wood_autochop*.png`（可用 `PF_SHOTS` 改目录）。 |
| `codex-test.js` | **图鉴单元测试（CI 用，v5.4.0）**：记录与计数、从旧档补图鉴、20 个成就里后期的保持锁定、连续不进店和动物心情的计数、里程碑、喂食后鲈鱼/锦鲤权重、狗的工作和边境牧羊犬偏好。 |
| `codex-smoke.js` | **图鉴浏览器测试（CI 用，v5.4.0）**：版本 5.4.0 / 存档 v10、图鉴三页签、狗自己去院子里转且会换工作、买鱼食和金鱼放进池塘解锁「锦鲤附体」、v9 存档迁上来能看见已钓到的鱼。 |
| `codex-shots.js [存档.json]` | 从图鉴面板、成就、里程碑、自转的狗、池塘观赏鱼和商店鱼食各拍一张，写入 `/workspace/pf-shots/v54_*.png`（可用 `PF_SHOTS` 改目录）。可带一份导出的存档。 |
| `weather-test.js` | **小雨和昆虫单元测试（CI 用，v5.4.3）**，不开浏览器：100 天里小雨间隔 7–10 天、每场 2–4 游戏时；下雨那天已种的田算浇过水、井边打水和浇水任务被跳过；离线跨天会补记下雨；夏天判定；昆虫按天气出没；捕虫网记入图鉴昆虫页并放走；`window.__insects.nearest`；v10 存档只追加字段不升版本。 |
| `weather-shots.js` | 拍小雨（涟漪、湿路）、蝴蝶蜻蜓和图鉴昆虫页，写入 `/workspace/pf-shots/v543_*.png` 和 `docs/img/`（可用 `PF_SHOTS` 改目录）。 |
| `soak.js [url] [秒数] [截图]` | 长时间运行测试，记录堆内存、缓存数量和画面是否空白。`PF_ANIMALS=1` 时先买齐四个棚子、全部动物和 6 只猫狗，镜头对着北牧场。`PF_FAMILY=1` 再加上庄园、篱笆、阿禾和两个孩子（四个人一起干活）。`PF_WOOD=1` 加上斧头升级、林场和伐木小屋。`PF_CODEX=1` 再放几条观赏鱼并打开图鉴面板。`PF_RAIN=1` 强制下一场长雨，用来量下雨时的帧耗时和内存。 |
| `roles-sim.js [天数] [存档.json]` | v5.3 分工：用真实游戏无头跑几天，打印每两个人 3 格 / 6 格内的时间占比、同时做同一种活的占比、两人都在干活时 3 格内的占比，以及每个人的活计构成。不给存档时自己建一个买齐区域和动物、阿禾已搬来的农场，`PF_KIDS=1` 再加两个孩子。 |
| `family-shots.js [tag]` | 阿禾 16 个方向和动作的特写（`ahe_closeups[_tag].png`），再跑农场拍 2–3 张两个人在不同区域干活的全景（`family_wide[_tag]_N.png`），写进 `/workspace/pf-shots/`（`PF_SHOTS` 可改）。 |
| `build_family.py [--preview out.png]` | 生成 `assets/family_sprites.js`：阿禾的新头像和长发、孩子只换身体颜色。 |
| `file.js` | 用 `file://` 打开 `index.html`，检查离线运行。 |
| `fps.js`、`bench.js`、`prof.js` | 帧率、加载耗时、性能剖析。 |
| `jitter.js`、`gid.js`、`pixeq.js` | 抖动和闪烁检查：静止时逐像素比较，旋转时比较缓存。`pixeq.js` 对比 8767（旧版）和 8765（新版）两个服务。 |
| `snap.js [query] [_] [out.png]` | 单张截图。 |
| `shots.js` + `closeups.py` | 生成 `shots/` 里的阶段截图和特写（`shots/` 不进 git）。 |
| `rec2.js`、`rotgif.js`、`tw_cap.js`、`tw_gif.js` | 录制帧序列，再用 ffmpeg 生成 mp4 和 GIF（产物不进 git）。 |
| `build_sprites_A.py` | 把 `assets/src/` 里的 SpriteCook 原图量化到调色板，生成 `assets/sprites.js`、`chars.png`、`crops.png`。 |
| `dl.py prefix url…` | 把 SpriteCook 的输出下载到 `assets/src/`。 |
| `views_to_voxels.py`、`viewer.html` | 早期体素模型工具和查看器。 |
