1.3.2 蜂箱搬家（#101，不加字段）：
- 玩家反馈：「蜂箱只能在放的那块花甸里用，挪不走，原来那块地就没法改用途（想再要一块动力坝）」。原因：六个蜂箱位只生成在第一块花甸上，「挪东西」也只许在原花甸里挪，所以旧花甸一直被占着。现在每块买下的花甸都有 6 个箱位，全农场仍最多 6 箱；用「挪东西」（手机 ⚒ 工具箱或电脑）可以把蜂箱挪到任何一块花甸，攒着的蜂蜜和产蜜倒计时跟着走，蜂蜜收集槽的蜜桶跟着蜂箱最多的那块花甸，集蜜槽照常接在每个蜂箱下。蜂箱全部挪走后旧花甸就能改建（比如改成动力坝）；还有蜂箱时商店会提示先用「挪东西」挪走。
- 测试：`node tools/works-test.js`；打包后的真触摸流程 `bash platforms/xhs/pack.sh && node tools/xhs-beehive-shots.js`（CI xhs-touch 组：⚒ → 挪东西 → 点蜂箱 → 移动 → 瞄非花甸被拒且不丢蜂蜜 → 瞄第二块花甸 ✔ → 其余 5 箱挪过去 → 再读档 → 旧花甸改成动力坝）。

## 代码规范要点

- 离线 H5 zip，页面不能 `fetch` / XHR / WebSocket，资源全部打进包。
- 兼容基线：Android 8.1 / Chrome 61，JS 交 ES2017；更新语法要转译。
- Canvas 2D 完整支持；本游戏只用 2D。
- 脚本必须外置经典 `<script src>`，禁止内联脚本、`onclick`、`type="module"`、`eval`、WASM。
- 存储：客户端 9.46+ 用 `window.xhs.miniTool.setStorage/getStorage`（单 key ≤1MB，整工具 ≤10MB）。`localStorage` 只作旧版降级。写入先写 `:bak` 再写主 key，加载时校验并回退备份；超配额会 toast，不会覆盖上一份好存档。游戏内每天早上、每 30 秒，以及 `visibilitychange` / `pagehide` / `freeze`（并探测是否有 `onHide`，官方 2026-11-13 清单里没有）会落盘。离线结算从 `savedAt` 起算，拒绝非有限/负间隔，未来时钟超过 60 秒不发离线金币，超长跨度封顶。手机端游玩记录收紧（30 天 / 200 事件 / 10 段会话），并关掉文件夹同步。
- 云存储（官方 §3.16，9.51+，内测）：`add/update/query/removeCloudStorage`，单条 `content` JSON UTF-8 ≤64KB（1003 超限），未授权 1005/1006 须降级。本包把它当作跨设备**主存档**：启动时同时读云和本地（Storage JS API §3.6/3.7，再降级 localStorage），按 `savedAt`（相同则比农场天数）取较新的一份，并回写到本地缓存；较新的本地会择机上传。云写入节流约 3 分钟，并在 `visibilitychange` / `pagehide` / `PFPlatform.flush` 时补写。查询失败不当作空档。后期存档约 39KB，低于 64KB 上限。CLI 的 `authorizations` 里 `apiCloudStore` 官方说明是「用户头像和昵称、用于排行榜」，**没有**单独的云存储权限编码；若创服网页把「云存储」列为高级能力或权限，须在表单上勾选，否则真机会 1006 降级到本地。
- 支付：禁用 `PaymentRequest`。买断走宿主支付墙，工具内无商品内购 API。赞赏用 `rewardAuthor`（成功回执不含金额）。排行榜 `submitScore/getRankList/getMyRank` 为 9.51+ 内测，须勾选头像昵称授权 `apiCloudStore`。一键发笔记用 `postNote`（官方 §3.3，以方法是否注入为准，无单独版本门槛）：`title`≤20 字、`content`≤1000 字、`pageType`、必填 `mediaInfo`（图片 1–18 张，`data:` 或 `writeTempFile` 路径）。文档没有话题字段也没有小工具卡片绑定字段，话题写在正文 `#标签` 里；默认文案在 `platforms/xhs/note-copy.js`，可改。大图先 `writeTempFile`；若能截到画布，优先带上玩家自己的农场，再附打包好的封面图。不给发笔记奖励（《小程序管理规范》§7.1 禁止分享立即获得利益、强制分享和暗示诱导分享）。用户取消或当前环境不支持时静默处理，入口藏在右侧图标列（系统分享按钮下方）的「更多」里。关注创作者用 `followAuthor` / `getFollowStatus`（官方能力清单 3.15，客户端 9.51+，版本门槛 9510），无业务参数，只能关注当前小工具作者；`follow_status` 为 -1 失败 / 0 未关注 / 1 已关注 / 2 作者本人。用户关闭确认（20002）或已有确认框（10003）保持静默；当日确认上限 10 次（15404）只轻提示一次。低版本或未注入 API 时隐藏入口，不打扰。CLI 草稿没有对应 authorization 字段。关注创作者入口已接 `followAuthor` / `getFollowStatus`（§3.15），放在底栏「关」和排行榜标题旁，不自动弹窗。未做「关注有礼」：小工具能力清单只把该 API 写成引导关注和刷新按钮状态；《小红书小程序管理规范》（2025-12-10）§7.6 明确禁止「关注立即获得利益」和用明示/暗示样式诱导关注，虚拟奖品（金币、优惠券、积分等）也在禁止之列；品牌号社区规范也将「关注就能领红包」列为诱导类作弊。因此只保留普通关注入口，不发放关注专属道具。
- 体积：zip 上限 10 MiB（建议 ≤2 MiB），解压 ≤30 MiB。

底栏和右上角按钮用变体 A 圆形木牌图标：主包放 `atlas_hud_128_q90.webp`（首屏：包/仓/店/随/关/榜/赞/速）和 `atlas_128_q90.webp`（全套，含预留的音乐/音效），不要进 `assets/`。图标下不再跟文字标签。游戏日志和台词不再用常驻半透明面板挡农场，改为 HUD 卡片下方一行（最多两行）约 3 秒后淡出的轻提示，没有底框。
已打包背景音乐和音效。官方预览/提审接口的文件类型白名单不含音频后缀（官方 zip 审计不拒 mp3，但 `preview` 会以「不支持的文件类型」驳回），且 CSP 禁止 `<audio>` 使用 `data:` / `blob:`，因此不能把 `.mp3` 放进 zip，也不能用 `<audio src="data:...">`。音乐按 64 kbps 立体声重编码后写成 base64 JS，由 `audio.js` 用 Web Audio `decodeAudioData` 播放：首屏 `res/audio-data.js` 只含清晨曲和核心音效；午/晚/夜各一份 `res/audio-afternoon.js` 等，以及额外音效 `res/audio-sfx-more.js`，在对应时段临近或需要时再动态插入脚本加载。文件尚未到位或解码失败时回退到程序生成音乐 / ZzFX。默认音乐和音效都关闭，须用户点右上角开关后才出声（规范 10.5.3 禁止自动播放）。关注创作者、云存储、赞赏若容器未注入或返回未授权，入口隐藏，存档静默降级到 Storage / localStorage，不弹错误。右上角「更多」里是官方分享卡片（`share` type=card，9.53+）、保存农场图到相册（`saveImageToPhotosAlbum`，9.42+）和赞赏（`rewardAuthor`，9.53.3+）；缺 API 则隐藏，不和分享/关注/赞赏绑定任何游戏奖励。关闭挽留赞赏默认不开。

竖屏包（`mobile.css` / `mobile.js`，只打进小工具 zip，网页版不加载）：framebuffer 240×426，按设备像素取最大整数倍缩放（iPhone 14 / 常见 Android 上为 4×），舞台在顶栏和底栏之间，避免页面滚动和双指缩放整页。默认跟随农夫，拖动画布会暂时关掉跟随；底栏是背包 / 仓库 / 商店 / 跟随农夫 / 关注作者 / 奖杯（排行榜 + 图鉴），没有存档和倍速按钮。触控目标 ≥44px。顶部系统返回（左）和分享（右）完全留空——真机是左右箭头，不是右侧胶囊。HUD 放在状态栏 + 约 44px 导航条之下，并用 `getWindowInfo().safeArea` / `statusBarHeight` / `menuButtons`（9.49+）精修；图标列在右侧分享按钮下方、且始终在 HUD 下面，避免互相遮挡。跟随农夫和关注作者都在底栏，不进顶角。双指捏合用非被动 `touchmove` + `gesturestart` 拦截，缩放与旋转会先判别再各自生效；旋转有增益和每帧/每次手势角度上限，避免转太快。横屏会压低顶栏并允许小于 1× 的 CSS 缩放，以免画布溢出，但小工具按竖屏来设计。
