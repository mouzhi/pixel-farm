# 像素小农场 · DESIGN

Surface: both（兴趣卡 + 兴趣卡落地页）
任务与核心交互：卡面上点土地播种 → 几秒长成 → 点成熟作物收获 → 金币即时上涨；落地页是一块可以挂机的小农场，承接卡面带来的金币，自动生长、离线收益、升级。

## 视觉方向

- 主视觉：一块 3×2 的像素土地（6 格松土，带像素描边），占卡面 Body 约 70% 高度；作物按「种子 → 幼苗 → 成熟」三帧像素图切换。戴草帽的像素小农夫站在田里，会走到被点的那块地干活（锄地 / 浇水帧动画）。
- 构图：中心聚焦。上方一行金币计数（像素金币图 + 大号数字），中间是田地主视觉，农夫叠在田地前景层（absolute，跟随目标地块移动），下方一行三个种子按钮。
- 背景利用：9:16 背景图是像素风农场晨光（红顶小屋、田垄、树林），卡面底板半透明，背景的绿色和暖光从底板透出来；底板内不再套大面板，土地格子直接落在底板上。
- 标题与关键字：金币数字用 DIN 数字字体、暖金色 #FFD34D + 深棕描边感投影（text-shadow 1px 四向）做出像素游戏 HUD 感；「+12」飘字同色；种子按钮用木板棕底 + 浅描边 + 像素作物图标。
- 高光动效：① 收获：成熟作物上方飘出「+金币」字，0 → -28px 上移并淡出，600ms；金币计数图标同时弹一下 scale 1 → 1.25 → 1，300ms。② 成熟提示：成熟作物上下轻跳（translateY 0 ↔ -3px，800ms 循环）并带金色光圈。只用 transform / opacity。
- 记忆点：真的有一个像素小农夫会跑到你点的那块地去锄地、浇水，和《像素放置农场》同一套美术。

## OpenCard

Layout: 无（按 widget 最小骨架扩展）
Components: button（只参考尺寸与圆角节奏，用于种子按钮）
分区：
- Header：金币状态行（左：金币图 + 数字；右：「已收获 N 次」小字）。这是宿主没有的实时状态，独立成行。
- Body：田地（2 行 × 3 格）+ 叠在前景的农夫；FMP 挂 Body。
- Footer：三个种子按钮（胡萝卜 / 卷心菜 / 南瓜，每个写成熟秒数），选择即生效，无确认按钮。
Header 内 Tag：无。
组件字段：作物名 ≤3 字，成熟秒数「4秒」；提示文案 1 行 ≤14 字。
变体与状态：
- 默认：6 格空地，提示「点空地，种下胡萝卜」。
- 生长中：地块显示幼苗图 + 底部细进度条。
- 成熟：成熟图轻跳 + 金色光圈。
- 收获：飘字 + 金币弹跳，地块回空地。
- Loading：Body 内 `widget-state-message`「农场开门中…」；Error：一行原因 + 「重试」。
状态信息：当前任务（种/收）在 Header 下方提示行不单独做，改为地块本身的状态表达；更完整的挂机、升级在落地页。
空间组织：Header 自然高度，Footer 自然高度，Body 承接余高，田地两行按 Body 高度等分，格子正方形 aspectFit 居中。
交互：
| 区域 | 动作 | 可见反馈 |
| --- | --- | --- |
| 空地 | 点击 | 种下当前种子，农夫走过去浇水，出现幼苗和进度条 |
| 成熟作物 | 点击 | 飘「+N」，金币数增加并弹跳，农夫锄地 |
| 生长中作物 | 点击 | 地块轻抖，提示剩余秒数 |
| 种子按钮 | 点击 | 按钮高亮（金色描边），之后播种用该作物 |
最小槽高预算（300）：padding 19 + Header 26 + 间距 8 + Footer 40 + 间距 8 → Body ≈ 199，两行地块各 ≈ 95，可读。436 档地块更大。
参考资产：/workspace/dy-farm-card/.agents/skills/douyin-interest-card-design/assets/component/button/example.tsx、example.css
适配方案：只保留 small 按钮的高度与圆角节奏；颜色改成木板棕 rgba(92,58,34,0.85)、选中金色描边 #FFD34D；不使用示例的 variant 体系。
背景：按 widget.md 写入 feed-card.json（设计稿不写 URL）。

## MicroApp（兴趣卡落地页）

风格：同一套像素农场美术；草地平铺做页面底，木板色面板，暖金色数字。
页面结构（自上而下，可纵向滚动）：
1. 头图（landing-hero，16:9）与标题「像素小农场」，下叠金币 HUD（金币 / 每分钟产出）。
2. 卡面收获承接条：显示「卡片里收获的金币 N」，按钮「收进农场」；领取后变为已领取状态。
3. 挂机农场：农舍 + 田地网格（初始 4 格，可扩到 9 格），每格自动播种 / 生长 / 由农夫自动收获；点成熟地块可手动立即收获。
4. 作物选择：胡萝卜 / 卷心菜 / 南瓜（后两者需金币解锁）。
5. 升级：扩建田地（+1 格）、施肥（生长加速 15%/级，最多 5 级）。
6. 离线收益：再次进入时弹出「离开期间收获 N 金币」，点「收下」关闭。
首屏背景关系：导航避让区与头图属于同一视觉面（头图从顶部铺起），HUD 压在头图底部。
与兴趣卡共享：作物图、土地、农夫帧动画、金币图标、金币数字样式。
存档：本机存档（本地缓存），卡面金币通过服务端按用户记录后一次性收进农场。
