# 像素小农场 · DESIGN

Surface: both（兴趣卡 + 兴趣卡落地页）
任务与核心交互：卡面就是《像素放置农场》里自家农场的一角，玩法和游戏一样「看它挂机 → 钱够了 → 买东西升级」：田里的菜按时间自己长熟，点田地或「一键收菜」收掉换金币；金币够了，Footer 的「小店」变绿跳动并挂「可买 N」，点开小商店买扩地、雇家人、新作物、水井、鸡舍、主屋，买完农场画面当场变样（多一列田、阿禾来帮忙、换种新菜、田上落水滴、鸡和小猪住进来、门前多花盆长椅石灯、烟囱冒烟）。离开一段时间再回来，先看到离线结算。落地页是完整的《像素放置农场》。

## 视觉方向

- 主视觉：游戏引擎原样渲染的农场一角（农舍、水井、池塘、一大块待开垦的空地），占卡面 Body 宽度 100%、约 300px 高。地块（连土带菜）、小动物、装饰、主角和阿禾都是同一视角从引擎拆出来的精灵，叠在场景上；买了什么，就把对应精灵放进场景。
- 构图：斜俯视的游戏视角。农舍在左上，田地在右下（一开始只开垦左边 3 列，扩地往右长）；「熟了 N 块」金色气泡挂在田地上方；鸡在农舍左下草地，小猪在农舍右上；离线结算是压在场景顶部的深木色横条；小商店是盖住整个场景的深木色面板（3 行 × 2 格）。
- 背景利用：9:16 背景图保留原像素农场晨光；卡面底板半透明，场景图自带圆角。Header 一行（天数/时间 + 金币），Footer 一行（状态 + 小店 + 收菜按钮）。
- 标题与关键字：金币数字用 DIN 数字字体、暖金 #FFD34D + 深棕四向描边；「+312」飘字同色加大；「熟了 N 块」「一键收菜」、商店里买得起的价格按钮用金色底深棕描边；「小店」买得起时绿色 + 红色「可买 N」角标；买不起的价格按钮是灰木色。
- 高光动效：① 一键收菜：土留在原地重新播种，熟菜按列依次上浮放大并淡出（0.8s，列间隔 50ms），田地上方飘总金币「+N」，金币图标弹一下，主角挥锄。② 阿禾收菜：她走到那块地、冒「收菜！」气泡，地块上方飘「+8」。③ 买得起：「小店」上下跳 3px、角标「可买 N」，状态行变成绿色「钱够了，去小店升级」，商店里买得起的格子金边、价格按钮呼吸。④ 买到手：商店收起，新东西从上方弹进场景（0.6s，缩放 0.4→1.15→1，新开的一列田按列错开），同时飘一张奶油色小纸条（「田多了 4 块」「两只鸡住进来了」…）。⑤ 买不起时点价格：按钮轻抖并显示「差 N」。只用 transform / opacity（人物走位沿用 left/top 过渡）。
- 白天黑夜：按手机本地时间。5:00–17:00 白天图，17:00–19:00 白天图叠暖色傍晚层，19:00–5:00 换引擎渲染的夜景图；夜里阿禾回屋睡觉（窗边 Zz），菜照样长，水滴停。时段叫法和游戏一致。
- 记忆点：卡面不是「像游戏」，而是游戏本身的循环在卡里跑——攒钱、买、看着农场一点点变热闹。

## OpenCard

Layout: 无（按 widget 最小骨架扩展）
Components: 无（按钮、气泡、商店为自绘像素风）
分区：
- Header：左「第 N 天」+「07:42 清晨」，右金币图 + 数字。第 N 天从第一次在卡上看到农场那天算起。
- Body：农场场景（宽 100%，比例 704:680），地块、道具、人物、气泡、飘字、离线结算、小商店面板都在场景内绝对定位；FMP 挂 Body。
- Footer：左两行状态（「地里 N 块熟了」/「钱够了，去小店升级」/「下一茬 N 秒后熟」；「阿禾在帮你种地 · 已收 N 筐」/没雇时「已收 N 筐 · 小店能雇阿禾」/夜里「阿禾睡了 · 夜里菜也在长」），中间「小店」（56×40），右收菜按钮（有熟的：金色「一键收菜」；没有：木色「等它长大」，点了会轻抖）。
Header 内 Tag：无。

### 小商店

点「小店」打开、点 × 或再点「小店」关上；面板盖住场景，固定 3 行 × 2 格，不滚动不拖动。每格：图标、名字 + Lv、下一级效果一行、价格按钮（买得起金色呼吸，买不起灰色，满级显示「满级」并整格变淡）。点格子就买：扣金币、升一级、面板收起、场景里出现对应变化。各项 3 级，价格逐级变贵；排序按首价从低到高。

| 项目 | Lv1 / Lv2 / Lv3 价格 | 效果 | 场景变化 |
| --- | --- | --- | --- |
| 扩地 | 60 / 180 / 450 | 田 12 → 16 → 20 → 24 块（每级往右多开一列，新地从种子长起） | 新的一列土和幼苗弹出；满级田边立起稻草人 |
| 雇家人 | 80 / 250 / 700 | 阿禾来帮忙：每 5 秒 → 3.8 秒 → 2.8 秒去一趟，满级一次收两块（熟的不到 4 块时只浇水，留给你收） | Lv1 阿禾出现在田边，之后走得更勤 |
| 新作物 | 100 / 300 / 800 | 一开始只种胡萝卜（20 秒 8 金）；依次解锁卷心菜（30 秒 12 金）、草莓（40 秒 16 金）、南瓜（55 秒 22 金），四行田轮流种已解锁的菜 | 对应几行当场换成新菜（弹出） |
| 水井 | 120 / 360 / 900 | 生长速度 ×1.25 → ×1.5 → ×2 | 白天田上落水滴（2 → 4 → 6 滴） |
| 鸡舍 | 150 / 400 / 1000 | 卡片开着时每 10 秒小动物产出 +3 → +7 → +14 金 | 两只鸡 → 再来两只 → 一头小猪；鸡会低头啄食，旁边飘「+3」 |
| 主屋 | 200 / 600 / 1500 | 离线每分钟 6 → 10 → 15 → 22 金，最多算 8 → 10 → 12 → 16 小时 | 烟囱冒烟；Lv1 门口两盆花，Lv2 屋旁长椅，Lv3 路边两盏石灯 |

经济节奏：第一次打开 12 块地里约 2/3 已熟，收一次正好 64 金，够买第一样（扩地 60）；之后每样都是「挂一会儿 → 够了 → 买」。

变体与状态：
- 第一次打开：12 块地里大半已熟，气泡和金色按钮一眼可见，金币 0，「小店」是木色。
- 买得起：见高光动效 ③。
- 离开 ≥2 分钟再回来：顶部结算条「你离开了 5小时40分 / 阿禾帮你收了 374 筐菜（没雇阿禾时：地里攒下了 N 筐菜） / +7,480 / 收下」，按主屋等级算；点「收下」才入账。
- 生长中：作物按阶段图切换；阿禾去浇水。
- 收获、购买：见高光动效 ①④。
- 傍晚 / 夜晚：见白天黑夜。
- Loading：Body 内「农场开门中…」；Error：一行原因 +「重试」。
存档：只存在卡片本机缓存（key pf-card-farm-v3：金币、已收筐数、24 块地的播种时间、六项商店等级），不联网、不上报、不读游戏存档；卡面金币和商店等级是卡上的小农场自己的，不承诺带进游戏，也不和关注、分享、打赏挂钩。
空间组织（343×436）：padding 约 14 + Header 26 + 间距 6 + 场景约 302 + Footer 约 46；商店面板 = 场景大小（标题行 26 + 3 行格子各约 85）。
交互：
| 区域 | 动作 | 可见反馈 |
| --- | --- | --- |
| 田地 / 「熟了 N 块」气泡 / 「一键收菜」 | 点击 | 熟菜按列飞起淡出，「+N」飘字，金币弹跳，主角挥锄，地块重新种下 |
| 「等它长大」 | 点击 | 按钮轻抖，状态行写着下一茬还要几秒 |
| 「小店」 | 点击 | 打开 / 关上小商店面板 |
| 商店格子（买得起） | 点击 | 扣金币、面板收起、场景里新东西弹进来、小纸条说明 |
| 商店格子（买不起） | 点击 | 价格按钮轻抖，显示「差 N」 |
| 商店 × | 点击 | 关上面板 |
| 离线结算「收下」 | 点击 | 结算条消失，「+N」飘字，金币弹跳入账 |
性能：一张场景图 + 一张地块图集（24 块地共用）+ 一张家人帧条 + 一张道具帧条；只在卡片可见时每秒走一次钟、鸡舍每 10 秒结一次；没有 Canvas、没有网络请求（平台固定的卡片数据接口除外）。
背景：按 widget.md 写入 feed-card.json（设计稿不写 URL）。

## MicroApp（兴趣卡落地页）

风格：同一套像素农场美术；草地平铺做页面底，木板色面板，暖金色数字。
页面结构（自上而下，可纵向滚动）：
1. 头图（landing-hero，16:9）与标题「像素小农场」，下叠金币 HUD（金币 / 每分钟产出）。
2. 卡面收获承接条：显示「卡片里收获的金币 N」，按钮「收进农场」；领取后变为已领取状态。
3. 挂机农场：农舍 + 田地网格（初始 4 格，可扩到 9 格），每格自动播种 / 生长 / 由农夫自动收获；点成熟地块可手动立即收获。
4. 作物选择：胡萝卜 / 卷心菜 / 南瓜（后两者需金币解锁）。
5. 升级：扩建田地（+1 格）、施肥（生长加速 15%/级，最多 5 级）。
6. 离线收益：再次进入时弹出「离开期间收获 N 金币」，点「收下」关闭。
首屏背景关系：导航避让区与头图属于同一视觉面（头图从顶部铺起），HUD 压在头图底部。
与兴趣卡共享：作物图、土地、农夫帧动画、金币图标、金币数字样式。
存档：本机存档（本地缓存），卡面金币通过服务端按用户记录后一次性收进农场。
